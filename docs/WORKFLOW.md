# Working flow
1. Map stakeholders under an account (NTT DATA) with Reports To hierarchy.
2. Log every interaction as an Activity (Call/Email/LinkedIn/WhatsApp/Meeting/Event).
3. Activity updates the contact and creates a follow-up Task.
4. Formal meetings progress L1 -> L2 -> L3; highest stage is derived automatically.
5. At/after L3, a Requirement (REQ-2026-001…) is raised, linked to contact + source meeting.
6. Requirement moves New -> Profiles Shared -> Interviews -> Offer Made -> Closed Won/Lost / On Hold (Kanban, audited).
7. Reports, pipeline, org chart and quiet-contact lists are all views over the same data.
